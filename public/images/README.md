# Photo guide — exact file names

**How it works:** rename your photo to the exact name below and put it in the folder shown.
It appears on the website automatically. If a photo is missing, the section keeps its normal design.

- Allowed formats: `.jpg`, `.jpeg`, `.png`, `.webp` (best), `.avif`
- Names are lowercase, use hyphens, no spaces. Example: `bg-industries.jpg` ✅ — `BG Industries.JPG` ❌
- While testing (`npm run dev`): just refresh the page. On the live site: run `npm run build` again.
- Use photos you own or are licensed to use.

Text stays readable automatically:
- **cover** photos get a dark overlay with white text on top.
- **bg-…** photos on light sections get a strong white wash (subtle texture behind the text).
- **bg-…** photos on dark/navy sections get a navy wash.

### Tips
- Keep each photo under ~500 KB (compress at squoosh.app or tinypng.com). Big files slow the site.
- Covers look best with the subject on the **right** side — the text sits on the left.
- For backgrounds behind text, calm photos work best (texture, blurred office, machinery close-up).
- Real photos of your own team, office, installations and equipment build far more trust than stock photos.
